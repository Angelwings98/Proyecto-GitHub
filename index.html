2.1 Instalación y configuración

Instalé Git y configuré mi identidad.

git config --global user.name

2.2 Mi primer repositorio

Con git init creé la carpeta oculta .git.

Estados: untracked, modified, staged y unmodified.

2.3 Ciclo de vida

  1. Editar el archivo
  2. Revisar con git status
  3. Preparar con git add
  4. Guardar con git commit

2.4 Exclusión con .gitignore

Ignoro secretos, registros y archivos temporales.

*.log

3.1 Ramas

Una rama me permite experimentar sin romper main.

git switch -c feature/nueva-idea

3.2 Fusiones y conflictos

Un conflicto aparece cuando dos ramas cambian la misma línea.

Linea para conflicto Master

git merge feature/seccion-3-2

3.4 Historial y recuperación

Con log, diff, revert, reset, reflog y stash nada se pierde.

git reflog

4.1 Remotos y GitHub

Mi repositorio vive en GitHub: origin apunta a mi cuenta y sincronizo con fetch, pull y push.

git remote -v

4.3 Pull requests

Propongo cambios en una rama, mi pareja los revisa y se fusionan en main.

4.2 Flujo de trabajo y push

Mi flujo diario: trabajo en una rama, guardo con commits y subo mis cambios a GitHub con push.

  1. Crear la rama: git switch -c feature/seccion-4-2
  2. Editar el archivo y revisar con git status
  3. Preparar los cambios: git add index.html
  4. Guardar: git commit -m "Agrega sección 4.2"
  5. Subir la rama: git push -u origin feature/seccion-4-2
  6. Abrir el pull request en GitHub para fusionar en main
git push origin main
